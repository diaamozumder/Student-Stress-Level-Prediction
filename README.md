# 🎓 Student Stress Level Prediction Using Machine Learning

## 📌 Project Overview

Student Stress Level Prediction is a Machine Learning-based classification project designed to predict students' stress levels using academic, lifestyle, social, and personal factors.

The system classifies students into three categories:

- Low Stress
- Moderate Stress
- High Stress

The main objective is to explore how different factors influence student stress and investigate how Machine Learning algorithms can be used for stress-level prediction.

## 🎯 Project Objectives

- Identify factors associated with student stress.
- Collect and analyze student survey data.
- Apply Machine Learning classification algorithms.
- Compare the performance of multiple models.
- Predict student stress levels based on collected information.

## 📊 Dataset Information

The dataset was collected through an anonymous Google Form.

| Dataset Details | Information |
|---|---|
| Original Responses | 100 |
| Usable Records | 98 |
| Features | 26 |
| Target Variable | Stress Level |
| Classification Classes | Low, Moderate, High |

## 🤖 Machine Learning Models

Five classification algorithms were implemented:

1. Logistic Regression
2. Decision Tree
3. Random Forest
4. K-Nearest Neighbors (KNN)
5. Support Vector Machine (SVM)

## 📈 Model Performance

The following table shows the test accuracy achieved by each model.

| Model | Accuracy |
|---|---:|
| Logistic Regression | 55% |
| Decision Tree | 70% |
| Random Forest | 70% |
| KNN | 70% |
| SVM | 60% |

Decision Tree, Random Forest, and KNN achieved the highest test accuracy of 70%.
